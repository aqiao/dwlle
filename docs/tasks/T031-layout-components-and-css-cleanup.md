## 目标

清理历史迭代留下的无用 DOM/CSS，并将页面顶部和左侧导航拆成可复用组件，保持现有界面和交互不变。

## 范围

- 从 AppShell 拆出 Sidebar 和 Topbar 独立 React 组件。
- 保留 Workspace/Environment 选择器、工作空间设置、个人菜单和移动导航。

- 移除隐藏的推广卡片 DOM 及样式。
- 不根据简单文本匹配删除动态状态类，避免误删。

1. AppShell 仅负责布局和状态组合，Sidebar/Topbar 可独立复用。

3. 页面视觉和交互无回归，build、lint 和全部测试通过。
4. 在 `task/T031-layout-components-and-css-cleanup` 分支提交，提交信息以 `T031:` 开头。
