# T027：统一 Workspace 工作空间术语

状态：已完成
日期：2026-11-03

## 目标

将 Project 统一调整为 Workspace，消除项目逻辑组与运行治理边界之间的歧义。

## 范围

- 接受 ADR-0014，明确 `Tenant → Workspace → Environment → Scenario → Pipeline`。
- 更新现行架构、路线图、月底计划、README 和候选能力备忘，不改写历史 ADR。
- 原型导航“我的工作空间”改为“日常工作”。
- 页面、按钮、统计、安装记录、API 示例和测试中的项目统一改为工作空间。
- 不改变生产 Alpha 范围和交互逻辑。

## 验收标准

1. 文档与界面不再混用 Project/项目与 Workspace/工作空间。
2. 导航为日常工作，新建按钮和统计均使用工作空间。
3. build、lint、测试、Markdown 链接和 diff 检查通过。
4. 在 `task/T027-workspace-terminology` 分支提交，提交信息以 `T027:` 开头。
