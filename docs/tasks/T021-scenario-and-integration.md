# T021：场景分层与 REST/MCP 集成基线

状态：已完成
日期：2026-11-03

## 目标

将解决方案/项目、业务场景、Pipeline 三层抽象，以及公共 REST 与 FastMCP 集成方式纳入项目文档和高保真界面原型。

## 范围

- 接受 ADR-0011：解决方案、场景和 Pipeline 的职责、版本与环境绑定边界。
- 接受 ADR-0012：前端与外部应用共用领域 REST，FastMCP 与 REST 共用应用服务。
- 更新 ARCHITECTURE、ROADMAP、README 和 11 月功能边界。
- 原型新增：
  - 解决方案目录与安装/环境绑定流程。
  - 业务场景列表、跨 Pipeline 依赖、数据契约和场景运行状态。
  - REST/MCP 开发者集成页面。
  - DAG 的项目/场景上下文。
- 更新导航和交互测试，验证桌面与移动布局。

## 非目标

- 不实现真实场景调度、解决方案安装、REST 服务或 MCP Server。
- 不在 Alpha 中实现多层场景嵌套、跨项目 Pipeline 引用或公开交易市场。
- 不允许通过 MCP 绕过应用服务直接访问 DS、数据库或云资源。

## 验收标准

1. 两项 ADR 为已接受，架构明确区分可共享定义与环境绑定。
2. REST 与 FastMCP 共用应用服务和权限/审计上下文，不存在重复业务逻辑或直接数据访问。
3. 原型可点击“解决方案安装”“场景查看”“API/MCP 集成”路径。
4. `npm ci`、`npm run build`、`npm run lint`、`npm test` 和 `npm audit` 通过。
5. 桌面和 390px 移动视口可用，Markdown 本地链接和 `git diff --check` 通过。
6. 在 `task/T021-scenario-and-integration` 分支提交，提交信息以 `T021:` 开头。
