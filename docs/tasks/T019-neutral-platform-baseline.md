# T019：平台中立架构与 11 月 Alpha 基线

状态：已完成

## 目标

将“AWS 首发、平台中立、开源数据平面、全自研用户界面”的方向正式设为项目基线，并形成可执行的 2026 年 11 月内部 Alpha 计划。

## 范围

- 接受 ADR-0009，明确 SaaS 控制平面、开源数据平面和 AWS 基础设施适配边界。
- 新建并接受 ADR-0010，明确客户可见界面全部由 dwlle 自研，DolphinScheduler 只作为后台执行引擎。
- 更新被取代或部分取代的历史 ADR 状态，不删除历史记录。
- 将 `ARCHITECTURE.md` 更新为唯一的现行架构文档。
- 以 `PROJECT_PLAN_2026-11.md` 为月底交付计划，重写 `ROADMAP.md`。
- 更新 README 和文档索引。
- 不修改 `phase1/`，不编写平台实现代码。

## 验收标准

1. ADR-0009、ADR-0010 为“已接受”，旧决策的取代关系明确。
2. 现行架构不再同时维护 StarRocks 旧路线和中立新路线两份有效文档。
3. 客户可见 UI、Pipeline 事实来源和 DS 后台职责无歧义。
4. 月底计划包含 P0/P1/不做范围、资源前提、里程碑、每周安排和端到端验收。
5. README、ROADMAP、ADR 索引和任务说明相互一致。
6. Markdown 本地链接有效，`git diff --check` 通过。
7. 所有变更在 `task/T019-neutral-platform-baseline` 分支提交，提交信息为英文且以 `T019:` 开头。
