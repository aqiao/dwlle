# T022：我的工作空间与方案市场边界

状态：已完成
日期：2026-11-03

## 目标

明确日常企业实例与外部共享模板的信息架构，统一使用“方案市场”命名，避免自己的 Solution/Scenario/Pipeline 与其他用户内容混在同一列表。

## 范围

- 接受 ADR-0013，区分工作空间实例与方案市场模板及其安装/升级生命周期。
- 更新主架构和原型说明，不改变 11 月生产 P0/P1 和里程碑。
- 原型导航调整为：
  - 我的工作空间：工作台、业务场景、Pipeline、运行中心、SQL。
  - 数据管理：数据资产、数据源。
  - 方案市场：解决方案、场景模板、Pipeline 模板、已安装与更新。
  - 开放集成：API 与 MCP。
- 新增场景模板、Pipeline 模板和已安装与更新页面。
- 解决方案页改为只展示官方/社区模板，不混入企业运行实例。
- 更新测试并验证桌面与移动视图，提交到 Git。

## 非目标

- 不实现真实安装、升级、支付、共享发布或市场后端。
- 不改变当前生产 Alpha 的功能边界。
- 不使用“资源中心”或容易与 Data Mart 混淆的“数据集市”。

## 验收标准

1. 工作空间只显示企业自有或已安装实例，方案市场只显示共享模板和安装管理。
2. 模板与企业实例的定义、修改和运行边界在文档与界面一致。
3. 新增页面可导航，现有 7 项测试及新增测试通过。
4. build、lint、test、audit、Markdown 链接和 diff 检查通过。
5. 在 `task/T022-workspace-and-solution-market` 分支提交，提交信息以 `T022:` 开头。
