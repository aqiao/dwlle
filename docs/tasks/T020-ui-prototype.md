# T020：11 月 Alpha 高保真界面原型

状态：已完成
日期：2026-11-02

## 目标

在 `web/` 中实现一套可点击的高保真界面原型，用于验证 dwlle 的视觉风格、信息架构和核心用户流程，为后续控制平面开发确定 UI 基线。

## 范围

- 使用 React 18、TypeScript、Vite，匹配 ADR-0007。
- 实现统一应用壳：侧边导航、项目/环境切换、全局搜索、通知和用户入口。
- 实现核心页面：
  - 工作台：任务、成功率、告警、资源和最近运行概况。
  - Pipeline 列表：状态、调度、负责人和运行信息。
  - 自研 DAG 编辑器：节点、连线、组件面板、属性面板和发布流程原型。
  - 运行中心：实例列表、节点状态、日志和 AI 失败诊断。
  - SQL IDE：库表树、编辑区、结果表格和查询历史。
  - 数据资产：表清单、Schema、质量与表级血缘。
  - 数据源：连接列表、状态和连接配置原型。
- 提供原型交互：页面导航、Pipeline/运行实例切换、节点选择、面板开关、运行/发布反馈和基础筛选。
- 提供桌面和窄屏响应式布局，以及键盘焦点和基础可访问性。
- 配置 ESLint、Vitest 和构建脚本，覆盖核心导航与交互。
- 所有数据均为明确的前端模拟数据，不连接 AWS、DS、Trino 或模型。

## 非目标

- 不实现后端、真实 OIDC、权限、持久化和 API。
- 不实现真实 DAG 拖拽布局算法、SQL 执行或任务调度。
- 不引入 DS 原生 UI、iframe 或深链接。
- 不实现 P0 之外的高级调度、BI 市场和生产级主题系统。

## 验收标准

1. `npm run dev` 可打开完整原型，核心页面均可从侧边导航访问。
2. 用户可完成“Pipeline 列表 → DAG 编辑 → 发布反馈”和“运行实例 → 失败节点 → AI 诊断”两条点击路径。
3. 页面无横向意外溢出，窄屏可使用导航和主要内容。
4. `npm ci`、`npm run build`、`npm run lint`、`npm test` 通过。
5. 原型不依赖后端服务，不暴露真实凭据，不修改 `phase1/`。
6. 在 `task/T020-ui-prototype` 分支提交，提交信息以 `T020:` 开头。
