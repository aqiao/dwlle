## 目标

## 范围

- 从左侧移除“开放集成”分组。
- 右上角通知旁增加“工作空间设置”，点击打开现有 API 与 MCP 页面。

3. build、lint 和测试通过，文档链接和 diff 检查通过。
4. 在 `task/T029-settings-navigation` 分支提交，提交信息以 `T029:` 开头。
