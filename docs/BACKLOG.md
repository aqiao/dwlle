# 产品候选能力备忘

状态：仅备忘，未立项
更新日期：2026-11-03

> 本文记录后续可能评估的产品能力，不构成架构决策、优先级承诺或交付计划。当前 ADR、`ROADMAP.md` 和 2026 年 11 月 Alpha 的 P0/P1、里程碑与资源安排均不因此改变。启动前须另行评审并创建 ADR 和任务说明。

## 1. BI 与可视化分析

### 初步方向

- 复用 Apache Superset 等成熟 BI 能力，通过受控方式嵌入 dwlle-web，不重写完整 BI 引擎。
- 基于平台 Dataset、权限和血缘提供看板、图表、交互查询和定时报告。
- 评估统一的业务语义层、指标口径、行列级权限和租户隔离。
- 与 Scenario 关联，展示业务就绪状态、数据质量和分析结果。

### 启动前需评估

- Superset 嵌入、Guest Token 与 dwlle OIDC/RBAC 的映射。
- 数据权限是否由 BI、Trino 或统一应用服务强制执行。
- 与自研 SQL IDE 的职责边界及性能、资源成本。

## 2. Solution / Scenario / Pipeline 交易与共享

### 初步方向

- 允许作者发布、共享或售卖 Solution、Scenario 和 Pipeline 的版本化包。
- 支持免费/付费、作者主页、版本、兼容性、安装量、评分和更新通知。
- 安装时继续遵循“定义与环境绑定分离”，由购买者绑定自己的资源、密钥和权限。
- 提供审核、签名、安全扫描、权限声明、成本估算和可移植性检查。

### 启动前需评估

- 作者身份、知识产权、内容审核和恶意代码处置。
- 支付、分账、退款、税务、发票和平台抽成。
- 许可证、商业使用范围、源码可见性与后续升级权。
- 第三方组件的供应链安全、依赖锁定和漏洞撤回机制。
- 跨版本兼容、售后支持和买方数据安全责任边界。

## 与当前计划的关系

- 不改变当前以 AWS 首发、平台中立和 11 月内部 Alpha 为目标的实施范围。
- 不在当前版本中增加 BI 页面、公开/付费市场、支付或第三方内容上传。
- 现有 Solution/Scenario/Pipeline 领域模型可作为未来评估基础，但不预设上述能力一定实施。
