# 0001 AWS 原生，部署在客户账号，同时支持 aws / aws-cn
状态：已接受
日期：2026-10-09

## 背景
目标客户是国内中小企业。部分客户可开通 AWS Global 账号，部分必须使用 AWS 中国区（北京/宁夏）。团队有深厚的 AWS 经验，Bedrock AgentCore 已在中国区上线。

## 决策
- 只支持 AWS，不做多云抽象。
- 以 CDK 应用的形式部署到**客户自己的账号**，不做 SaaS 托管。
- 同一套代码必须同时支持 `aws` 与 `aws-cn` 两个分区。

## 理由
- 数据不出客户账号，避开 SaaS 的数据安全审查。
- 多云抽象会使两人团队的工作量翻倍。
- 客户数据含境内个人信息时，存放于 Global 区属于数据出境，需安全评估或标准合同，中小企业难以承担，因此中国区是刚需。

## 后果
- 所有 IaC 和代码不得硬编码分区相关的 ARN、域名、服务端点。
- 每个功能都要在两个分区各验证一次，CI 中两个分区都要 `cdk synth`。
- 产品文档需引导：含个人信息的数据部署在中国区。
