# 0006 部署时不从公网下载，所有安装包走 artifacts bucket
状态：已接受
日期：2026-10-09

## 背景
中国区访问 GitHub、Docker Hub、Apache 镜像站时，速度慢且不稳定。部署过程中从公网下载，会导致部署失败或结果无法复现。

## 决策
- 所有第三方安装包和容器镜像，在部署前由 `scripts/stage-artifacts` 上传到客户账号的 artifacts bucket（镜像也可以推送到 ECR）。
- EC2 的 user data 和安装脚本只从 S3 / ECR 获取，**禁止**使用 `curl` 访问公网地址。
- 所有版本号集中定义在一个版本清单文件中，并逐一校验 sha256。

## 理由
保证两个分区都能部署成功、结果可复现，并且版本可审计。

## 后果
- 首次部署多一个准备步骤。安装包从哪里获取（本地或中国区镜像源）由准备脚本处理。
- 升级流程变为：更新版本清单，上传新的安装包，再执行滚动替换。
